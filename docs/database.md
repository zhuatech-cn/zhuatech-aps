# 数据库说明

Copyright 2026 上海如静知华信息科技有限公司。

| 表 | 业务含义 | 主要关系 |
| --- | --- | --- |
| `aps_work_center` | 车间工作中心与计划产能 | 被工单、资源引用 |
| `aps_user` | 登录账号、岗位角色和所属中心 | 操作工可绑定工作中心编码 |
| `aps_work_order` | 产品、批次、计划/完工/不良数量 | 关联工作中心 |
| `aps_operation_report` | 工序、合格数、不良数、人员和时间 | 关联计划订单 |
| `aps_inspection` | 首检、巡检、完工检验 | 关联计划订单 |
| `aps_equipment` | 资源运行状态、OEE 与心跳 | 关联工作中心 |

所有表包含 `created_at` 和 `updated_at`。生产部署建议根据工厂规模对反馈、采集和追溯表实施分区或归档，并对工单号、批次号、资源编码和采集时间建立组合索引。
